# bugriyev.com

Author website for Pavel Bugriyev, PhD, and *Back to Church, Back to Hope*.

Plain static HTML/CSS (no build step), served by GitHub Pages from the `main` branch root, custom domain `bugriyev.com` (see `CNAME`).

- `index.html`, `about.html`, `book.html`, `contact.html`: the four pages (shared header/footer are repeated in each file).
- `styles.css`: all styling.
- Contact form: FormSubmit (formsubmit.co), no backend. First submission triggers an activation email.
- Email signup: Kit embed placeholder in `index.html` (search for `KIT`).
